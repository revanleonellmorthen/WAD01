Rvn Belajar adalah komunitas untuk pemula yang ingin membuat halaman web sendiri. Materi dimulai dari struktur semantik sampai layout Flexbox dan Grid.

Apa yang dipelajari

HTML Semantik

Memakai tag header, main, section, dan footer agar struktur jelas.

Layout Flexbox

Menyusun elemen sejajar dengan display: flex dan justify-content.

Styling CSS

Mengatur warna, jarak, dan ukuran agar halaman nyaman dibaca.
